# ioniq-hud-nav

EV trip planning for a 2023 Hyundai IONIQ 6 whose head-up display only shows the car's own navigation.

The iPhone app plans the trip and its charging stops. It sends each next charger to the car's navigation through Bluelink, and the car guides on the HUD. No server, no subscription.

| Path | What |
| --- | --- |
| `core/` | Rust, no dependencies, no I/O: models, planner, protocols. Tested anywhere with `cargo test`. |
| `ffi/` | UniFFI bridge exposing the core to Swift. |
| `ios/` | SwiftUI shell: UI, network, GPS, Keychain. Project generated by XcodeGen. |
| `scripts/ios-build.sh` | Builds and installs the app on the paired iPhone (run on the Mac). |
| `docs/STATE.md` | Where the project stands. Read this first. |
| `docs/DECISIONS.md` | Decisions taken, one line each. |
| `docs/LESSONS.md` | Failures and the prevention added for each. |

Unofficial project, not affiliated with Hyundai. The Bluelink API is undocumented and may change.

Credentials never enter this repository: they live in the iPhone Keychain only.
